🚀 Cómo alojar en GitHub + Render y activar tu Bot real

  1. Crear el Bot en Telegram (1 min): Abre Telegram, busca @BotFather, envía /newbot y copia el token que te da.
  2. Subir este proyecto a GitHub: El proyecto ya incluye render.yaml y .gitignore listos. Sube la carpeta a tu repositorio de GitHub.
  3. Conectar con Render (Onrender.com): En Render haz clic en New + → Web Service (o Blueprint), selecciona tu repositorio de GitHub y añade en Environment Variables: TELEGRAM_BOT_TOKEN = tu token de BotFather.
    Envía /miid a tu bot en Telegram para que te diga tu ID y ponlo en TELEGRAM_ADMIN_CHAT_ID.
